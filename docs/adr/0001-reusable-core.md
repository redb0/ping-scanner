# Ядро для сканирования

Логика сканирования (зондирование + оркестровка) реализована в отдельном внутреннем пакете,
а не в `main`. Интерфейс командной строки (этап 1) представляет собой тонкий транспортный
слой поверх этого пакета; веб-сервис (этап 2) будет представлять собой ещё один
транспортный слой поверх того же ядра.

Мы предпочли такой подход одноразовому интерфейсу командной строки на `main.go`, чтобы
на этапе 2 можно было просто сменить транспортный слой, а не переписывать код.
Таким образом, семантика параллелизма, тайм-аутов и кодов завершения создаётся и
тестируется один раз в ядре, а не заново для каждого транспортного слоя.
